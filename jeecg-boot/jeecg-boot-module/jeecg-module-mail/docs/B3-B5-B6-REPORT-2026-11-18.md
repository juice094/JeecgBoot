## 3. 设计取舍（与计划书一致）

- 正文实时 FETCH 不落库（最小驻留 + 与 B-2 索引口径一致）；打开详情即已读（Outlook 口径）
- 删除语义：Trash 映射优先，无映射永久删除（QQ「Deleted Messages」未识别属已知，映射后自动变软删）
- 写信归档 Sent 失败仅告警（未映射 Sent 不影响发送结果）
- 未做（明确不在本期）：正文搜索、附件上传写信、幂等键去重、to-todo/biz-links/agent 封存线

## 4. 遗留与建议

1. ReadingPane 仍是纯文本渲染；html-only 邮件本地剥标签展示（格式损失可接受，引入富文本渲染须先解决邮件 XSS 消毒，无新依赖前提下不划算）
2. QQ「Deleted Messages」等 4 个未识别文件夹映射后，删除语义自动变软删（UI 已有提示入口）
3. 同步 N+1 性能风险为存量已知项（二期批量 upsert）
