不解决，注册后 MailSyncScheduler 与 MailCompensationTask 的 @Scheduled 全部不生效，冒烟 §6.2 / §7.1 直接 ❌。

两个选项：

| 选项 | 做法 | 影响面 |
|---|---|---|
| A | JeecgSystemApplication 加 @EnableScheduling | 全单体；与 cloud 版行为一致；改动公共文件 |

**建议 A**：单体本来就有补偿类需求（team 侧也有定时任务可能后续要加），且 cloud 版已是 A 口径，保持一致。
