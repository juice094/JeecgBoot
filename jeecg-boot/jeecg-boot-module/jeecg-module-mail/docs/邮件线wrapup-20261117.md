## 3. 坑（对后续施工者）

1. **mavenrc_pre.cmd 曾强制 mvn 用 JDK 25 → Lombok 静默失效**（症状=满屏"找不到符号 方法 getXxx()"，零 Lombok 报错）。D-77 已修（条件式钩子）；若复发：MAVEN_SKIP_RC=1 + JAVA_HOME=jdk-17.0.12+7。
2. 根 pom `skipTests=true`：跑测试必须 `-DskipTests=false`。
3. `Transport.connect()` 无参不读 JavaMailSenderImpl 字段凭据 → 必须显式 4 参 connect（A-1/B-1 各一处）。
4. SMTP 错误分类：JavaMail 连接失败文案自带 `; timeout NNNN`，连接特征必须优先于超时；分类常量注意后缀化（防 smtp_smtp_* 双前缀）。
5. greenmail 包名是 `com.icegreen` 不是 `org.icegreen`——"程序包不存在/CNFE"先逐字对包名，再怀疑环境（教训来源：查了二十分钟"JVM 灵异"）。
6. `com.sun.mail.imap.*` 实现类不在编译类路径：用 `jakarta.mail.UIDFolder` 接口；mock 用 `extraInterfaces`。
7. MyBatis-Plus 3.5.16 的 `insert/updateById` 有集合重载：Mockito `any()` 歧义，用 `any(Entity.class)`。
