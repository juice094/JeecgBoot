## 2. 同步引擎关键口径（B-3 需求落点）

| 需求 | 实现 |
|---|---|
| last_uid 游标增量 | `getMessagesByUID(lastUid+1, UIDFolder.LASTUID)`，拉完游标推进 max(uid) |
| 只写信封索引不存正文 | ENVELOPE+FLAGS fetch；正文按需 FETCH 属 B-3；snippet=pilot 占位（取主题） |
| 重复同步不重复记录 | 唯一键 (account,canonical,imap_uid) 先查后插；已存在只刷新 readFlag |
| 未识别不静默跳过 | 落 oa_mail_folder_state（canonical 空）+ WARN，经 mapping 接口人工归一 |
| error 不回退游标 | 游标只在批次成功后 update；异常向外抛，下轮续跑 |
| 事务 | 刻意不加 @Transactional（长 I/O）；逐条 upsert + 游标幂等兜底 |

## 4. 踩坑记录（教学价值）

- **greenmail 包名是 `com.icegreen`，不是 `org.icegreen`**。症状诡异：javac 报"程序包不存在"、运行期 CNFE、javap 找不到类，但 `jar tf` 与 .NET 都能列出条目、字节流完整可读——查了二十分钟"JVM 灵异事件"，最后 manual defineClass 报 `wrong name: com/...` 一击定位。**教训：先验证 import 包名与 jar 内路径逐字一致，再怀疑环境。**
- `com.sun.mail.imap.IMAPFolder` 不在编译类路径（实现类，starter 只给 API）：改用 `jakarta.mail.UIDFolder` 接口（`instanceof UIDFolder` 判断），mock 用 `extraInterfaces` 技巧。
