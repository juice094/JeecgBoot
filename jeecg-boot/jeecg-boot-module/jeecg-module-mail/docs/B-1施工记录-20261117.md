## 2. 施工中揪出的两个真 bug（已修）

1. **no-arg `Transport.connect()` 不读 JavaMailSenderImpl 凭据**：username/password 是 sender 字段，不进 session 属性，真实握手持久报 "no password specified?"。改为显式 `connect(host, port, user, pass)`。**影响面**：若带到 Phase 2 运行时，A-1 测连与 B-1 绑定会 100% 误失败。
2. **分类器双前缀 + 优先级**：常量带 "smtp_" 前缀又被加前缀（smtp_smtp_timeout）；且超时优先会让 JavaMail 连接失败文案（自带 “; timeout NNNN” 配置值后缀）全被误判为超时。修复：后缀化常量 + 连接类特征优先。
