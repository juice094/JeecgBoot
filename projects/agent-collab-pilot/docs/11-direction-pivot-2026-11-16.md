# 11 — 产品方向调整：团队协作效率工具（正向道路）

> 2026-11-16，技术总监指示，宿传达。本文档为方向裁决存档，后续设计以此为准。

## 一、指示原文要点

1. **先完成基础功能**（tools / 团队协作效率工具）——这是产品主线。
2. **完成基础功能前，不允许搞"池号那一套"**——账号池、隔离浏览器批量登录 webAI 等，不得进入开发排期。
3. **那一套不能作为产品设计**——仅可作为研究资料封存，不进产品范围、不进对外文档。
4. 开发研究**正向道路的团队协作效率工具**。

## 二、范围重定义

### ✅ 产品范围（正向道路，基础功能）

| 模块 | 内容 | 实现策略 |
|---|---|---|
| 组织权限 | 用户/角色/部门/租户（RBAC） | JeecgBoot 裁剪保留 |
| IM 沟通 | 单聊/群聊/频道/语音消息/文件传输 | Mattermost 组装 + SSO |
| 文档协同 | 多人实时同步编辑、版本历史 | OnlyOffice 组装 |
| 文件管理 | 团队文件盘、全格式在线预览 | MinIO + KKFileView |
| 任务协作 | 任务/看板/指派/截止提醒 | jeecg 自研轻量模块 |
| 日程公告 | 团队日历、公告通知 | jeecg 自研轻量模块 |
| 审批流 | 请假/报销等常用模板 | 轻量状态机（自研）或 Flowable |
| 接口文档 | 代码即文档，团队共用 | Knife4j（已有） |
| 音视频会议 | 1v1/群组语音会议 | Jitsi / Mattermost Calls（后置） |

### ❌ 封存研究线（不作为产品设计，不进排期）

- 账号池生命周期（docs/02 的账号池部分、`accounts` 表的池化用法）
- 隔离浏览器执行池（docs/02、ROADMAP 原 W4）
- AI 会话采集与 session 复用（docs/08）
- Agent 注册调度（docs/04 的调度部分）
- WSS 网关与设备准入（docs/01 §准入）——**降级**：作为研究线保留，待基础功能完成后再评审是否重启

说明：封存 ≠ 删除。相关文档保留在 pilot/design 分支原位置，仅在产品设计引用层面除名。若未来重启须经技术总监重新拍板。
