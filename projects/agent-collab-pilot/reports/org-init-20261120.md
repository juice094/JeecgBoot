## 3. 新建组织的初始化口径（模板复用说明）

对后续新建组织，本套初始化 = 两份 SQL 材料 + 现有角色体系：

1. 组织结构：照 A05 模型建部门树（公司→部门→岗位三级，`org_category` 1/2/3，`org_code` 前缀递进制）；
2. 成员：建用户（HrManage 页，自动获标配角色）→ 挂部门节点 → 按身份在角色分配页叠加蓝鸥成员/业务主管/管理员；
3. 日常维护唯一出口：HrManage（用户/部门）、RoleManage（角色/权限），不再直写 SQL。
